# mousarchitect.github.io

MousArchitect's architecture &amp; design portfolio site, built on GitHub Pages
using a customized version of the [Phantom](https://html5up.net/phantom)
template by HTML5 UP.

## Structure

- `index.html` — Home
- `about.html` — About
- `portfolio.html` — Portfolio
- `contact.html` — Contact
- `assets/`, `images/` — template CSS, JS, fonts, and images

Search the HTML files for `TODO` comments — they mark placeholder copy,
images, and links that still need real content before this replaces the
site currently live at mousarchitect.design.

Deployment is automatic via `.github/workflows/static.yml` on every push to
`main`.
